# MWZProtocol Developer Documentation

**PUBLIC REPOSITORY**

Public documentation for integrating with MWZProtocol DEX and Warzone Markets.

## Purpose

This repository contains:
- Getting started guides
- Integration tutorials
- API reference
- Market data documentation
- Trading integration examples
- Chain support documentation
- Event schemas
- Smart contract interfaces
- Versioning and stability information
- Error handling guidelines
- Rate limiting expectations

## What's NOT Here

❌ Private architecture or masterplans
❌ Internal security procedures
❌ Private threat models or economics
❌ Deployment procedures
❌ Operational runbooks
❌ Secrets or credentials

Private architecture documentation lives in the private mwz-docs repository.

## Public API Status

⚠️ **PRE-RELEASE**: Documentation covers planned and implemented features.

Planned features are marked as `PLANNED`.

Implemented features are documented with examples.

Until v1.0.0 is released, APIs may change. See [Versioning](./versioning/) for stability information.
